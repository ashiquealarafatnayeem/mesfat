# Mesfat Ara Maysha — Portfolio

Personal portfolio website of **Mesfat Ara Maysha**, Law student at Bangladesh University of Professionals, public speaker, debater, host and founder of *Law & Rights with Mesfat*.

Design by Team [Reach Rider](https://reachrider.com/). Static version for GitHub Pages.

## How to update the site

| What to change | Where |
|---|---|
| Gallery photos, YouTube videos, social links | `content.js` (instructions inside) |
| Photo files | `images/gallery/` |
| Profile & section images | `images/` (keep the same file names) |
| Achievements, education, clubs, publications, skills | `assets/app.js` (lists at the top) |
| Other text (hero, about, contact) | `index.html` |

After editing a file, upload it again on GitHub (Add file → Upload files). The live site updates in 1–2 minutes.

## Main images (in `images/`)

| File name | Used for |
|---|---|
| `profile.jpg` | Hero profile photo |
| `law-rights-quote.png` | About section, under the quote |
| `law-rights-initiative.png` | Law & Rights with Mesfat section |
| `law-rights-mentorship.png` | Mentorship section |

If a file is missing, the site temporarily loads the copy from the Reach Rider server.
